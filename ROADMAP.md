# ECHO Roadmap

> "An embodied AI doesn't exist because it can talk. It exists because it can perceive, decide, act, remember, and share the same world as us."

## Vision

ECHO is an open-source framework for building embodied AI Player Characters (APCs).

Core principles:
- Embodiment before intelligence
- Perception before planning
- Validation before execution
- Safety before capability
- Modular architecture
- Deterministic fallbacks
- Open source first

## Completed Milestones

- Phase 0: Foundation
- Phase 1: Shared 3D world
- Phase 2: Embodied locomotion
- Phase 3: Structured perception
- Phase 4: Decision architecture
- Phase 5: AI connectivity
- Phase 6: AI decision bridge
- Phase 7: Object interaction
- Phase 8: Natural communication
- Phase 9: Persistent memory
- Phase 10: Persistent world

## Current Architecture

World → Perception → Brain → Legal Action → Action Controller → Interaction → Physics → World

Memory and AI support the loop but never bypass it.
